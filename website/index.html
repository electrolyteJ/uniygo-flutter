关于 uniygopro 你可能想知道的。

uniygopro 是一个基于 Flutter 的开源 Yu-Gi-Oh! Pro 游戏客户端，目标是让同一套代码运行于 Android、iOS、Windows、Linux、macOS 与 Web，提供 AI 对战、联机房间、卡组编辑等完整功能。
完全免费且开源。客户端代码托管在 GitHub，所有平台构建产物由 GitHub Actions 自动产出并发布到 Releases，任何人可自行下载、审计、二次开发。
会。项目接入 ProjectIgnis CardScripts 卡表资源，通过 git submodule 拉取，新卡发售后同步更新即可使用，规则实现贴近实卡。
支持。通过 WebSocket 联机房间可与好友实时对战，低延迟同步操作。房间服务可由社区或自建服务器提供，客户端已内置 duelink 联机模块。
Apple 不允许未签名 IPA 直接安装。CI 会产出未签名 IPA，需使用自己的 Apple 开发者证书签名后通过侧载方式安装，或自行编译。
克隆仓库后执行 git submodule update --init --recursive，在 apps/uniygopro 目录执行 flutter pub get 与 flutter build <platform> --release 即可。详情见仓库 README。
