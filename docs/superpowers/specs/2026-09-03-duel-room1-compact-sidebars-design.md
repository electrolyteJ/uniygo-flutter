# duel_room1 紧凑侧栏适配设计

## 目标

修复 `compact` 视口下卡片详情、区域浏览和确认列表仍沿用桌面宽侧栏的问题。侧栏保持左右停靠和覆盖式交互，但缩窄到适合手机横屏及 `800×450` PC 浏览器窗口的宽度。

## 适用范围

- 所有 `DuelRoomSizeClass.compact` 视口，包括 Android/iOS 原生横屏和紧凑 PC 浏览器窗口。
- `regular` 与 `wide` 保持现有桌面侧栏宽度和布局。
- 卡片详情抽屉、区域浏览面板、确认卡列表共用紧凑侧栏宽度规则。

## 宽度规则

- 紧凑侧栏目标宽度为安全内容区宽度的 `35%`。
- 目标宽度夹紧在 `220dp` 到 `300dp`。
- 当安全内容区不足 `220dp` 时，侧栏退化为安全内容区可用宽度，不产生负约束或横向溢出。
- 左右边距继续使用安全区与 `panelGap`，侧栏不得进入刘海、圆角或系统手势不可用区域。

## 左侧卡片详情

- 保持左停靠，不改变打开、关闭和检视状态流。
- 紧凑视口使用统一侧栏宽度，卡图按侧栏内容宽度和可用高度缩放，不再使用可能超过侧栏内容宽度的固定卡图尺寸。
- 标题栏、徽章、攻防信息和描述保持当前视觉风格；内容整体纵向滚动。
- 标题与关闭按钮固定可见，关闭按钮有效命中区域至少 `44×44dp`。

## 右侧区域与确认列表

- 保持右停靠和非模态点击穿透契约。
- 紧凑侧栏固定使用 2 列卡片网格；`regular/wide` 继续使用现有列数规则。
- 标题、数量、状态后缀和关闭按钮固定，网格及动作内容可滚动。
- 长卡名省略，不通过继续缩小卡片维持更多列数。

## 面板关系

- 沿用 compact 主要面板互斥顺序：卡片详情、确认列表、区域浏览同一时间只显示一个。
- 面板关闭后，保留状态的下一优先级面板按现有逻辑恢复。
- 侧栏作为叠层覆盖决斗区，不参与 Flame 相机 fit、缩放或平移计算。
- 打开或关闭侧栏时，决斗区位置和缩放保持不变。

## 测试与验收

- `640×360` 与 `800×450` 下，左右侧栏宽度等于安全内容区宽度 `35%` 经 `220–300dp` 夹紧后的结果。
- 带非对称安全区的 Android 横屏下侧栏不越过 `safeRect`。
- 紧凑右侧网格为 2 列；桌面 `1280×720` 及以上保持现有列数和宽度。
- 卡片详情卡图不超过内容区，标题和关闭按钮可见，内容可滚动。
- 左右侧栏均无 RenderFlex overflow，关闭按钮命中区域至少 `44×44dp`。
- 打开侧栏前后 Flame 相机 zoom 与 position 不发生变化。
